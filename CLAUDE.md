# The-best-skill

Coleção pública de skills. Regras para quem mexer aqui:

- Não altere o conteúdo de skills existentes em `skills/`. Melhorar = adicionar, nunca editar.
- Skill nova: pasta `skills/<nome>/SKILL.md`, com a origem registrada em `INDEX.md` e a licença em `licenses/`.
- Se o usuário pedir para instalar as skills em você, siga `INSTALL.md`.
